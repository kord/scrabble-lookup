## 🧠 What Is This?

A **real-time word affix analyzer** built with **React + TypeScript** that shows every valid prefix and suffix you can add to any word — powered by a trie-based dictionary lookup.

Type a word, and instantly see:
- **Prefixes** you can prepend (e.g., `un` → `unlock`)
- **Suffixes** you can append (e.g., `ful` → `helpful`)
- Color-coded visual highlighting of your input
- Grouped results by affix length
- Dark theme UI
